# Last deployment (before teardown, 2026-10-23)

The AWS stack was torn down to bring the project's cost to $0/month (`infra/deploy.sh teardown`).
This file records what was running, so it can be rebuilt as it was. It contains no secret
values: the database, reader, JWT and origin passwords are generated by Terraform on every
deploy, the demo password is the `demo_password` default in `terraform/variables.tf`, and the
only external key (OpenRouter) is passed in at redeploy time.

## Rebuild

```bash
docker info                                   # Terraform runs in Docker (infra/tf.sh)
aws sts get-caller-identity                   # AWS CLI v2, an account with the permissions below
export OPENROUTER_API_KEY=sk-or-...           # free Nemotron fallback; never written to the repo
infra/deploy.sh redeploy                      # bootstrap -> up -> LLM secret -> load -> smoke (~25-30 min)
```

The new CloudFront URL is printed at the end. It differs from the old one: a default
`*.cloudfront.net` domain is assigned per distribution. Update the links in DESIGN.md and
CLAUDE.md §10 if the project is shown again. Chat history, memories and traces are not
restored: they lived in the deleted database. The 2M-row dataset is regenerated identically by
`schema/generate_data.py`.

To tear down again: `infra/deploy.sh teardown`.
